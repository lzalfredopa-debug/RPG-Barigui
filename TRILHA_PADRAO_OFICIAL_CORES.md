# TRILHA — Padrão Oficial de Cores

Esta versão aplica a paleta cromática oficial em `tailwind.config.js` e `src/index.css`.

| Token | HEX | Uso |
|---|---|---|
| `gold` | `#D4B15A` | destaque e títulos em fundo escuro |
| `gold-bright` | `#E3C56F` | títulos/destaques fortes em fundo escuro |
| `copper` | `#8B4A3A` | organização, bordas e ações |
| `copper-dark` | `#6F392E` | títulos em fundo claro e botões |
| `ink` | `#2C241E` | texto principal em fundo claro |
| `parchment` | `#E7D8BC` | fundo claro e texto sobre fundo escuro |
| `card` | `#EFE4CF` | cards claros e texto principal sobre marrons |
| `dark` | `#231B16` | fundo principal escuro |
| `brown-dark` | `#4A4032` | cards escuros |
| `brown-mid` | `#5F5340` | agrupamentos médios |
| `white` | `#FFFFFF` | texto em botões de cobre |

## Regra de contraste

- `#231B16`: títulos dourados; texto `#E7D8BC`.
- `#4A4032`: títulos `#E3C56F`; texto `#EFE4CF`.
- `#5F5340`: títulos `#E3C56F`; texto `#EFE4CF`.
- `#E7D8BC`: títulos `#2C241E`/`#6F392E`; texto `#2C241E`.
- `#EFE4CF`: títulos `#6F392E`; texto `#2C241E`; secundário `#5F5340`.
- cobre/cobre escuro: texto branco.
- dourado: texto `#2C241E`.

Nenhuma tonalidade alternativa de dourado, cobre ou marrom deve ser criada sem revisão da paleta oficial.
